# Serial Listener · 串口侦听器

一个基于 Web Serial API 的单文件纯前端串口调试助手。

## 🌟 特性
- **单文件运行**：无需安装，一个 HTML 文件即可在浏览器（Chrome/Edge）中直接运行。
- **海量数据不卡顿**：底层采用字节级状态机与批处理队列，配合虚拟滚动，轻松应对大数据量。
- **自动分卷保存**：支持自动保存日志，并可在文件达到指定大小（如 1MB/2MB）时自动切割下载。
- **自动部署**：通过 GitHub Actions 自动同步代码至 Gitee 并部署至个人服务器。

## 🚀 如何使用
直接双击打开 `index.html`，或访问线上体验地址：[https://185.148.13.83](https://185.148.13.83)

## 🛠️ 部署说明
本项目配置了 GitHub Actions，任何推送到 `main` 分支的代码都会自动通过 SCP 部署至 VPS，并同步至 Gitee 镜像仓库。
